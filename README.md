# Marketing Adda — Brand Strategy Studio & Live Campaign Radar

A personal desktop & web application built with **Electron**, **Node.js**, and **Vanilla JavaScript** that brings **Alina Wheeler & Rob Meyerson's *Designing Brand Identity (6th Edition)*** together with a real-time startup and marketing trend engine.

## Live Demo
> Add your Render URL here once deployed: `https://marketing-adda.onrender.com`

## Features
- **Live Trend Pulse:** Aggregates real-time feeds (Google News India/Global, Inc42, YourStory, Reddit, Hacker News) using a custom zero-dependency Node.js RSS/XML parser and maps every story to Wheeler's 5-Phase Identity Process.
- **6th Edition Academy:** Interactive breakdown of Brand Fundamentals, Identity Elements, Modern Dynamics (AI, Sustainability, Rebrands), and the 5-Phase Methodology.
- **Adaptive Campaign Vault:** Curated Indian & global success stories plus 1-click pinning of live breaking trends.
- **Strategist Lab & Quiz:** Brand Brief generator, 25-point Brand Audit scorecard, and 10-question assessment.

## Run Locally
- **Desktop App:** `npm install && npm start`
- **Browser Mode:** `node server.js` (then open `http://127.0.0.1:3000`)
